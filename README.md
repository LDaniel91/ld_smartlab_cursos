# LD SmartLab — Plataforma de Cursos

Plataforma web educativa con cursos de **Informática, Ofimática (Excel, Word, PowerPoint), Inteligencia Artificial e Idiomas** (Inglés, Francés, Portugués, Alemán, Ruso, Italiano, Angolano).

## 🚀 Características

- 🎨 **Diseño responsive** con modo claro / oscuro persistente.
- 📊 **Motor de presentaciones reutilizable** (slides con navegación, índice y atajos).
- 🤖 **Curso de IA** con 9 herramientas analizadas (DeepSeek, Perplexity, Kimi, Claude, ChatGPT, Gemini, Copilot, NotebookLM, Qwen).
- 🌍 **Curso de idiomas** con vocabulario, frases, diálogos, notas culturales y autoevaluación interactiva.
- 📚 **7 cursos completos** organizados en 3 días cada uno.
- ⚡ **Arquitectura limpia**: HTML estructural, CSS modular, JS con datos separados.
- 💾 Preferencias guardadas en `localStorage`.

## 🧱 Tecnologías

| Tecnología | Uso |
|------------|-----|
| HTML5 | Estructura semántica |
| CSS3 | Variables, Grid, Flexbox, animaciones |
| JavaScript Vanilla (ES6+) | Motores de presentación, tema oscuro, quizzes |
| Font Awesome 6 | Iconografía |
| Google Fonts (Inter) | Tipografía |

> No requiere frameworks ni build step. Es un sitio 100% estático.
